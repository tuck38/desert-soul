## What is Desert soul?

Desert Soul is a 2D pixel art metroidvania currently going into the pre production phase. This game will include in depth combat systems, a uniqe story, and wild and zanny metroidvania style upgrades to change your playstyle.

## What the build features:

The Current Desert Soul build features a first area pass. This build features fall acceleration, the POC of the combat system, and responsive movement that has been tuned for the demo.

## To-Do List/Upcoming Features:

* A blocked out first area

* First metroidvania upgrade
* 2 basic enemy types
