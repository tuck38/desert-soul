## What is Desert soul?

Desert Soul is a 2D pixel art metroidvania currently going into the pre production phase. This game will include in depth combat systems, skill trees, a uniqe story, and wild and zanny metroidvania style upgrades to change your playstyle.

## What the build features:

The Current Desert Soul build features a movment sandbox where you can move around in a small 2D jungle gym. This build features fall acceleration, the POC of the combat system, and responsive movement that has been tuned for the demo.
